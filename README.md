# BR-Lua

## Use the [BR-LuaLauncher](https://github.com/tubaplayerdis/BrickRigsLuaLauncher/releases/tag/v1.0)

The game **might crash on injection.** Restart the game and launcher if this happens.

This project adds lua to Brick Rigs.

Made by American_Stig (tbgit) @Discord

## How it works

 - Lua is stored on **TextBricks**.
 - **Switch Bricks** have their `TickBrick` function overriden internally to run Lua code or have vanilla behavior.
